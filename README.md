# 🍊 Juice Mall - 100% Raw & Cold-Pressed Fresh Juices Website

A modern, responsive e-commerce storefront for **Juice Mall**, crafted using **React 19 + Vite + Tailwind CSS v4**.

![Juice Mall Preview](https://images.unsplash.com/photo-1613478223719-2ab802602423?auto=format&fit=crop&w=1200&q=80)

---

## 🌟 Key Features

1. **Attractive Hero Section**:
   - High-energy juice-themed aesthetics with warm citrus, tropical greens, and berry hues.
   - Dynamic floating badges (*Express Chilled Delivery*, *Hydraulic Pressed*, *Zero Added Sugar*).
   - Fast metrics ticker: 100% Cold-Pressed, 50+ Exotic Flavors, 15,000+ Happy Sippers, 4.9★ rating.
   - Direct jump action buttons to Menu, Special Offers, and Custom Blend Lab.

2. **Navigation Bar**:
   - Modern glassmorphic sticky header with backdrop blur.
   - Smooth navigation: **Home**, **Menu**, **Offers & Combos**, **Blend Lab**, **About Us**, **Reviews**, **Contact**.
   - Interactive Light & Dark mode switch with OS theme synchronization and persistence.
   - Shopping bag icon with animated item counter badge.
   - Fully responsive slide-down mobile navigation drawer.

3. **Juice Products & Menu Section**:
   - Categorized by: *Cold-Pressed*, *Superfood Smoothies*, *Detox & Cleanse*, *Citrus Boosters*, *Wellness Shots*.
   - Live search by flavor, fruit, or ingredient.
   - Quick dietary health benefit filters (*Immunity*, *Detox*, *Superfood*, *Hydration*).
   - Price sorting (*Low to High*, *High to Low*, *Highest Rated*).
   - Interactive product cards with hover 3D elevation, image zoom, nutrition info, discount badges, and instant "Add to Cart" feedback.

4. **Product Quick View Modal**:
   - Inspect high-resolution bottle views, nutrition breakdown (Calories, Natural Fruit Sugar, Vit C % DV), full ingredients, and allergen notices.
   - Quantity selector with instant checkout/cart addition.

5. **Special Offers & Combo Section**:
   - **Deal of the Day** with ticking live countdown timer (Hours : Minutes : Seconds).
   - Curated high-value bundle cards (*Sunrise Vitality Trio*, *Total 3-Day Green Reset Cleanse*, *Superfruit Antioxidant Party Pack*) saving up to 32%.
   - "Claim Deal" button with festive `canvas-confetti` explosion.
   - Interactive Promo Voucher Cards (`FRESHJUICE20`, `SUMMERSIP`, `DETOXLOVE`) with one-click copy and auto-apply.

6. **Interactive "Juice Blend Crafting Lab"**:
   - Build custom bespoke juices:
     - **Step 1**: Choose liquid base (Valencia Orange, Coconut Water, Apple Cider, Oat Milk).
     - **Step 2**: Pick 2 to 3 whole fruits & greens (Mango, Blueberries, Strawberries, Kale, Kiwi, etc.).
     - **Step 3**: Select superfood boosters (Ginger Shot, Blue Spirulina, Chia Seeds, Turmeric, Pea Protein).
   - Real-time estimated calorie meter & dynamic blend name generator.
   - Add custom blend directly to cart!

7. **About Us Section**:
   - The farm-to-bottle story: why cold-pressing matters over industrial heat pasteurization.
   - 4 Pillars of Excellence: *100% Organic Orchards*, *Hydraulic Cold Pressing*, *Zero Waste & Recyclable*, *Chilled Cold-Chain Delivery*.
   - Step-by-step 4-stage process roadmap.

8. **Customer Testimonials & Verified Reviews**:
   - Rating scorecard summary with 5-star distribution graph.
   - Verified buyer cards with flavor sipped, stars, and real reviews.
   - Interactive **"Write a Review"** modal allowing visitors to rate, enter thoughts, and see their review live!

9. **Contact & FAQ Section**:
   - Interactive inquiry form with validation and success banner.
   - Store location, operating hours (7 AM - 9 PM daily), hotline, and support email.
   - Expandable FAQ accordion addressing common questions.

10. **Interactive Slide-Out Cart & Checkout**:
    - Slide-over drawer with item stepper, instant removal, and clear cart.
    - Free chilled shipping threshold progress bar ($35+).
    - Promo code discounts applied in real time.
    - Full Checkout modal with delivery address, delivery time slots, payment selector, and instant order receipt with celebratory confetti.

11. **Footer**:
    - Newsletter subscription with immediate promo code voucher reward.
    - Social links (Instagram, Facebook, X/Twitter, YouTube).
    - Smooth "Back to Top" button.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Visual FX**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Fonts**: Outfit & Plus Jakarta Sans via Google Fonts

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone <your-repo-url>
cd juice-mall-website
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
